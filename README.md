# The Tasting Table

A Single Page Application built for **11.5 Lab: Single Page App** that creates an interactive dinner and drink pairing menu using live data from two public APIs.

## Features
- **API Mashup:** Uses the JavaScript `fetch()` API and `Promise.all()` to pull entrées from [TheMealDB](https://www.themealdb.com/) and beverage pairings from [TheCocktailDB](https://www.thecocktaildb.com/).
- **Ingredient Search & Quick-Picks:** Search by main ingredient or click quick-pick chips (`Chicken`, `Salmon`, `Beef`, `Lemon`, `Garlic`) to dynamically generate a paired menu without page reloads.
- **Chef's Choice Randomizer:** Generates a surprise entrée and cocktail pairing in one click.
- **Bistro Menu Design:** Styled with semantic HTML5 and a custom warm bistro color palette (`style.css`).
